# Python & Data Analysis — dokumentasi belajar

Dokumen ini merangkum bukti yang diperiksa dari arsip pembelajaran `code_snippets-master.zip`. Arsip tersebut berisi **492 file Python dan 18 notebook**; ZIP mentah tidak diunggah ke repository ini. Ringkasan ini adalah dokumentasi code-snippets dan latihan mandiri, bukan klaim pekerjaan klien atau pengalaman analis data produksi.

## Topik yang terlihat

- **Python dan Pandas:** DataFrame, indexing, filtering, update, baris/kolom, sorting, grouping dan aggregation, pembersihan data serta missing values, datetime/time series, dan import-export CSV/TSV/SQL.
- **Visualisasi:** Matplotlib untuk bar, pie, stacked chart, `fill_between`, histogram, scatter, time series, live data, dan subplots.
- **Ekosistem data:** NumPy, Jupyter Notebook, CSV, JSON, dan SQLite.
- **Pengambilan data dan aplikasi:** latihan API, web scraping, serta modul Flask yang ditemukan dalam materi belajar.

## Cara membaca dokumentasi ini

Arsip menunjukkan area yang dipelajari dan dipraktikkan melalui contoh kode. Ia tidak membuktikan deployment produksi, hasil bisnis, klien, atau jabatan formal data analyst. Karena itu, proyek ini ditampilkan sebagai catatan belajar yang dapat terus dikembangkan menjadi eksperimen atau dokumentasi yang lebih terarah.
